## 🛠️ Featured Projects
### [RPG Combat System](https://github.com/Vicente-Ballesteros/RPG-Combat) 🚧 In Progress
A text-based, OSRS-inspired turn-based combat system in Python, built to learn OOP from scratch.

- Character class hierarchy using inheritance (`Player`, `Enemy` from a base `Character`)
- Weapon system built with composition rather than inheritance
- Accuracy/miss-chance mechanics using a simplified hit-chance formula
- Multi-file architecture (`character.py`, `weapon.py`, `player.py`, `enemy.py`, `main.py`)

**Next up:** player action menu (attack/defend/heal), enemy variety, weapon progression
